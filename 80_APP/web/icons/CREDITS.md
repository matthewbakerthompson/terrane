# Icons and whose they are

The marks in this folder are the providers' and vendors' own, shipped as a curated subset so a
technology service or a bought system can carry the mark its reader already knows. `map.json`
says which file a name or a kind of component points at; `50_ENGINE/terrane/icons.py` does the matching;
`80_APP/tools/curate_icons.py` made the subset from the packages named below, which are theirs to
distribute and so are not in this repository. The provider icons are copied unmodified; the vendor
marks carry their brand color as a fill. Each set's terms, as published where it was taken from:

## AWS Architecture Icons, release 07312026 (Icon-package_07312026.zip, 14.0 MB)

Source: https://aws.amazon.com/architecture/icons/

AWS publishes the icons for customers and partners to use in architecture diagrams; the package's guidelines ask that icons are not modified or used to imply endorsement. The marks remain AWS's.

## Azure Public Service Icons V24 (Azure_Public_Service_Icons_V24.zip, 1.0 MB)

Source: https://learn.microsoft.com/en-us/azure/architecture/icons/

"Microsoft permits the use of these icons in architectural diagrams, training materials, or documentation. You can copy, distribute, and display the icons only for the permitted use unless granted explicit permission by Microsoft. Microsoft reserves all other rights."

## Google Cloud product and category icons (core-products-icons.zip, 319 KB; category-icons.zip, 796 KB)

Source: https://cloud.google.com/icons

Google publishes the icons for use in architecture diagrams of Google Cloud solutions; they are not to be altered, and the marks remain Google's.

## Simple Icons 16.34.0, the marks named in map.json

Source: https://simpleicons.org/

The SVG files are released under CC0 1.0 by the Simple Icons project; each mark is the trademark of its owner, and its use here is to name the vendor's product on a diagram, nothing more. Each file is given the brand color the collection records for it as a fill, since the files carry none.

## What is not here

ServiceNow, Workday, Collibra, Pegasystems, Experian, Onfido and NICE keep their marks out of
redistributable collections, so no file of theirs is shipped. A bought system from one of them
names its vendor in the technology line under its name instead, which says the same thing in words.

The collection no longer lists these marks, which is how it records one withdrawn at its
owner's request, so they are not shipped either, whatever the file server still serves:
adobe, alteryx, amazonaws, docusign, informatica, microsoft, microsoftazure, mulesoft, oracle, powerbi, salesforce, slack, tableau, twilio.
