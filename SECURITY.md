# Security

The app runs on your own machine and writes only to this working tree. The hosted
demo is static JSON with editing disabled, and neither makes third-party requests.
The things most worth reporting are ways a model file, an import or a request to
the local app could read or write outside the repository, or run code.

Report a vulnerability privately through
[GitHub's private vulnerability reporting](https://github.com/matthewbakerthompson/terrane/security/advisories/new),
not in a public issue.
